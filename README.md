# 咕噜日记 · Water Together

一个可爱温馨的多人饮水记录前端。输入昵称即可进入，能够添加多位成员，并按日期分别记录接水和喝水次数。

## 本地启动

```bash
npm install
npm run dev
```

## 当前功能

- 无密码昵称登录
- 登录时设置水杯容量、性别和固定头像
- 添加、切换多位饮水搭子
- 按日期查看和补记记录
- 日期支持前后翻页、直接选择某一天和回到今天
- 分别记录接水与喝水次数
- 独立记录上厕所次数
- 每人每日 8 次接水目标和进度（喝水次数不限）
- 全员当日统计与动态时间线
- 近 7 日汇总：每日接水/喝水次数与按杯容量估算的饮水量
- ECharts 当日饮水节奏折线图：按小时展示接水与喝水的次数集中度
- 单次操作撤销
- 按当前日期重置全员记录（清空前确认）
- 浏览器本地持久化（`localStorage`）
- 桌面与移动端响应式布局

## 数据说明

当前版本没有后端，所有成员和饮水记录仅保存在当前浏览器。后续接入账号系统或云端同步时，可以保留现有界面，仅替换数据读写层。
